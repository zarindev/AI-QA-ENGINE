Engineering highlights

Built to be trusted.

Agent loop

One action per Claude turn, an indexed element list plus screenshot, working memory and loop detection.

Self-healing replay

Every agent run becomes a replay script with multi-strategy locators; broken locators hand back to the agent.

Re-run verification

Failures run again: 3/3 confirmed, 1/3 flaky → needs review. Rule numbers re-computed in Python.

Permission matrix

Expected access from each role’s menus vs what direct URLs really allow — holes in red.

Privacy & safety

Safe Mode guard on every click, encrypted credentials, PII blur, authorization record.

Local, file-based

No database: atomic JSON writes, file locks, schema versions — zip a project and move it.
